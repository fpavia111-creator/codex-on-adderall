# Contributing
- Node 18+, no runtime dependencies. Please keep it that way.
- `npm test` must pass. Add a test with every behaviour change.
- Safety defaults (no destructive actions, allowlisted CLIs, hard budgets) are features. PRs that loosen them need an opt-in flag that is off by default.
- The product name lives only in `src/name.js`, `package.json` and the README title.
- Report security issues privately by email to Fpavia111@gmail.com, not in public issues.
- Contributions are licensed MIT.
