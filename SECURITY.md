# Security Policy

## Reporting a vulnerability

Please report security issues privately, not in public issues:

- Use GitHub private vulnerability reporting: the **Security** tab of this repo, then **Report a vulnerability** (https://github.com/fpavia111-creator/codex-on-adderall/security/advisories/new), or
- Email francisco@1111websites.com.

Include what you found, how to reproduce it, and the version affected.

This is a small, independently maintained project. There is no guaranteed response time or SLA, but reports are read and fixes are made as quickly as practical. Only the latest released version gets security fixes.
